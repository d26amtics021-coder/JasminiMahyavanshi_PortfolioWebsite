# Jasmini Mahyavanshi - Personal Portfolio Website

Mini-project for IT4048: Version Control with Git and GitHub.
Asha M. Tarsadia Institute of Computer Science and Technology (AMTICS), Surat.

A responsive personal portfolio built with HTML, CSS and JavaScript and hosted on GitHub Pages.

**Live website:** https://d26amtics021-coder.github.io/JasminiMahyavanshi_PortfolioWebsite/

## Sections
Home, About, Skills, Projects, Contact, Resume download, Footer links.

## Files
- `index.html` - page structure
- `style.css` - styling and responsive layout
- `script.js` - mobile menu
- `assets/profile.jpg` - profile photo
- `assets/resume.pdf` - downloadable resume

## Run locally
Open `index.html` in any browser. No build tools are required.
